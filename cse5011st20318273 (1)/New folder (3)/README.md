# EcoStay Retreat - Dilhan's Adventure Edition

A unique mountain adventure-themed resort booking application built with Android Studio and Firebase.

## 🏔️ Unique Features

- **Adventure Command Center**: Extreme expedition alerts and survival updates
- **Mountain Shelter Booking**: Search-based room system with adventure-themed accommodations
- **Button-Grid Activities**: 2x3 interactive button layout for adventure activities
- **Wilderness Areas**: Vertical button stack for nature reserve exploration
- **Adventure Notifications**: Storm watching, survival training, and expedition alerts
- **Horizontal Room Cards**: Unique layout with image positioning on the right

## 🎯 Technical Highlights

- **Platform**: Android (Java)
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **UI Framework**: Custom adventure-themed Material Design
- **Build System**: Gradle 8.5
- **Theme**: Blue adventure theme with orange accents

## 🚀 Quick Setup

1. **Extract** this zip file to your desired location
2. **Open** Android Studio
3. **Import** project (File → Open → Select the extracted folder)
4. **Wait** for Gradle sync to complete
5. **Build** the project (Build → Make Project)
6. **Run** on emulator or device
